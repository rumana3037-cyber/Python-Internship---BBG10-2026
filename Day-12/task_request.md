#.1---Concept Explanations 

-> ​Client vs. Server: A Client (like a web browser or a Python script) is the device or program that initiates a request for data or a webpage. A Server is a remote computer that stores the website's files or data, processes the incoming request, and sends back a response. 

​-> HTTP GET Request: An HTTP GET request is a method used by a client to ask a server to retrieve and send back specific data (such as a webpage or JSON data) without modifying anything on the server.
